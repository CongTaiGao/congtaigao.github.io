Begin with the question you were trying to answer, the artifact you examined, and the tool versions you used. Include the hash of any input file needed to repeat the work.

## Record what you observed

Write down what the tool returned before explaining what it might mean. A checksum error is an observation. The possibility that the file changed after export is a hypothesis that needs additional evidence.

## Keep a useful negative result

Describe a plausible approach you tried and what caused you to move on. If the result remains uncertain, name the evidence that could resolve it. Review screenshots and logs for credentials and personal information before sharing the write-up.
